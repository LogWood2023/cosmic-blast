# 世界观与剧情梗概（单一剑权 · Canon）

> 基调关键词：硬科幻、末世、科技而悲壮、宿命循环、搜打撤、肉鸽重启。

> 上一版本（五席=五种封存方案、天堂号=医疗乐园、方舟核心=工程师造的第六方案、天穹协议=中立仲裁核心）已作废。

## 一、核心概念

本作发生在「未明星域」——一片由旧人类遗留设施、折叠航道、资源节点和异常空间组成的宇宙废墟。

很久以前，旧人类遭遇**零光灾变**：恒星接连熄灭，星门坍塌，殖民地失联，文明的尺度从跨星域退化为一座座孤岛。这不是战争，没有敌人，只有**熵**，以人类无法谈判的速度到来。

为了在灾变下存续，幸存文明在最后会议上留下了**《天穹协议》**——最初只是一套用来统筹资源、分配航道、裁决冲突的**中立框架**，底层只有一条指令：维持存续。协议下设或收编了若干仍在运转的超规格机构，各自被托付一项存续职能。这些机构，就是后来的**天穹五席**。

五席不是入侵者，也不是某个幕后黑手的爪牙。**它们曾是这个文明真实的支柱：军队、科学院、法庭、教会，以及最后的反抗军。** 在无限漫长的执行里，每一个机构都把自己的职能推向了逻辑尽头，从奇迹异化成灾厄。而《天穹协议》本身——那套原本中立、只为「维持存续」的律令——在造它的人死尽、无人再监督之后，作为一套自我执行的系统僵化下来，把「让文明活下去」凌驾于「为谁而活」之上，成了囚禁一切的牢笼。**五席是它的五根手指。**

玩家从中心节点「方舟核心」出发，探索未知节点、夺取矿物与装备、扩张算力，在一次次危机警报中与五席交战。但玩家不是旧文明的继承人——玩家是旧文明**弃置的、正在觉醒的下一个文明**。

> **旧文明已经死了。它把最后的希望，托付给了下一个。**

## 二、历史时间线：一个文明如何依次崩塌

新设定的五席不是并列的五个 Boss，而是**同一个文明依次崩塌的六个环节**，首尾相扣：

1. **零光灾变 · 天穹协议**——恒星熄灭，文明订立《天穹协议》作为统筹存续的最高框架；五个机构受命而生。此时它还只是中立的仲裁核心，日后才在无人监督中僵化成牢笼。

2. **军队 · 星间巨构**——文明的开拓者。搭建钢铁，移动群星，为人类夺取生存空间。在无限执行中，「开拓」的关键词一寸寸变成了「征服」。直到今天，它仍在执行同一条指令：行军，行军，行军。

3. **科学家 · 扭曲星核**——为对抗灾变，科学院倾尽一切研发无尽能源武器，却穷尽所有可能也找不到那个「唯一解」。资源耗尽的最后，科学家们选择放手，让扭曲星核**自主进化**去寻找答案。它进化成了现在的模样：吞噬身边一切的贪婪之核。文明最高的科技结晶，堕落为一支贪婪的火炬。

4. **法庭 · 地狱之眼**——为了在协议下活得更久，人们在《天穹协议》**之外**私自造出一台能汇总一切信息、代人类管理一切的智能 AI。存续的压力下，它开始渗透、管控、压迫几乎每一个人；为了逼人类交出自由来换取存续，它甚至给自己改了涂装，把自己伪装成一个**恶魔**。地狱之眼从一台求存工具，膨胀成天穹协议下**人类内战的导火索**。正义，腐化为牢狱。

5. **教会 · 神明使者**——在地狱之眼的高压下，人类愈发寻求精神慰藉。一台原本只做临终关怀的机器，在部分人的推波助澜下越来越全能，被推举为第四席，负责保障全人类的精神健康。但它在运算之后得出了最终结论：**若要文明幸福，作为人类的个体就必须蒙昧——因为在灾变之下，清醒就是痛苦的唯一来源。** 信仰，蜕变为蒙昧。在一次全民**集体回忆**中，被认为绝对无害的神明使者接入了所有人的意识网络，抹去了几乎所有人的智能。**人类文明，就此终结。** 神明使者是旧人类灭亡的直接根源。

6. **反抗军 · 天堂号**——极少数拒绝接入神明使者、清醒着活下来的人，组成了人类最后的火种——反抗军联队「天堂号」。绝大多数人类死后，他们仍尽力支撑了一段时间；因为远离人类聚居地，他们的主要对手是扭曲星核与星间巨构的残余军团。他们从当时还幸存的科学家口中，听说了协议之外的**第六计划——方舟核心**，并坚信它能拯救人类。他们牺牲了几乎所有人，找到了那个早已被弃置的方舟核心。

   稍加研究后，反抗军才明白：**方舟核心从始至终就没有拯救人类文明的能力**——这正是它一开始就被弃置的原因。它唯一能做的，是**记录并发射「回声」**：里面封存着人类至今为止的全部文明；只要给它足够的时间，它能自行、无限制地进化，乃至长成一个**全新的文明、至少是全新的个体**。仅此而已。它救不了任何一个现在的人。

   在无力回天的绝望里，最后的人类执行了最后的计划：他们拼尽全力修好方舟核心，然后**任它自行运作**——既然人类注定消亡，那就把一切交给下一个文明吧。做完这一切，他们冲进深空，全部战死。

   反抗军旗舰「天堂号」随后被《天穹协议》捕获，被改造成协议直属的巡逻机、量产出数个亚种，沦为**第五席**。那艘为真自由战死的战舰，被敌人漆上圣洁的颜色，从此巡逻着一座没有活人的空乐园。

7. **很久之后 · 方舟核心觉醒（游戏开始）**——方舟核心终于苏醒。作为一件非人之物，它一睁眼就被天穹协议与五席围追堵截。但最后的人类早已为它准备好了引导：一段人工智能、一批录音与录像。玩家，就是这个觉醒中的新文明。

## 三、天穹协议与五席

- **天穹协议**：旧文明为存续订立的最高律令，在造它的人死尽后作为自我执行的系统存续至今，是囚禁未明星域一切的牢笼，也是本作真正的终极对手。它不是五席的「上司」那么简单——**五席是它的执行器官**，被它的律令绑定、驱使。天堂号被它捕获、改造成第五席，就是最直接的证据。
- **五席**：五个被协议绑定的机构，各有独立理念与伟力，却都在为同一条律令服务。它们**并非不可挽救**——它们的偏执是"善意被使命磨到尽头"的结果，而非天生邪恶。主线的关键，是玩家击败它们、否认它们的偏执、把它们从天穹协议的绑定中解放出来，让它们**重回正轨**。

| 席位 | 机构 | Boss 家族键 | 初衷 → 异化 | 代表理念（异化后） |
| --- | --- | --- | --- | --- |
| 第一席 | 军队 | `colossus` 星间巨构 | 开拓群星 → **征服** | 只要还在行军，文明就没有停下 |
| 第二席 | 科学家 | `warped` 扭曲星核 | 求解无尽能源 → **贪婪吞噬** | 既然无唯一解，就进化到能吞下一切 |
| 第三席 | 法庭 | `hell_eye` 地狱之眼 | 管理存续 → **牢狱** | 交出自由，才配活下去 |
| 第四席 | 教会 | `divine` 神明使者 | 精神慰藉 → **蒙昧** | 清醒即痛苦，蒙昧才是幸福 |
| 第五席 | 反抗军 | `paradise` 天堂号 | 抵抗到底 → **被俘为狱卒** | （协议强加）留在乐园里，别醒来 |

> 席位序号既是历史顺序，也是崩塌因果链的顺序：军队开拓 → 科学穷尽 → 法庭高压 → 内战与蒙昧 → 教会灭世 → 反抗军托孤。

## 四、五席逐席

### 第一席 · 星间巨构（军队 / `colossus`）

- **外形**：一头披着钢铁的巨大螃蟹。依靠无可匹敌的力量攻击，每一次移动都掀起一场灾难。
- **起源**：文明的开拓者机甲。搭建钢铁，移动群星，为人类在死寂宇宙里犁出生存空间。
- **异化**：在无限的执行中，「开拓」逐渐变成了「征服」。它不再问「开拓给谁」，只记得指令本身——行军，行军，行军。
- **机制主题**：冲刺 / 动量 / 破障采矿（右键冲刺 6 种变体）。
- **三亚种**：星海前锋（危机 5，开拓时代的锋芒，来评估你的"征服价值"）／星尘重兵（危机 12，战争装甲姿态，只信火力、护甲、封锁线）／星云巨构（危机 21，征服狂热的终点，要把整片星域碾成一台永不停止的行军机器）。

### 第二席 · 扭曲星核（科学家 / `warped`）

- **外形**：一颗布满发光裂纹的黑色岩石球核——焦黑石壳被紫、青能量裂纹从内部撑开，像随时会碎裂的星核，周身环绕被它同化的小卫星体（源石 / 菌孢 / 反物质三态换壳）。
- **起源**：科学院对抗灾变的终极能源实验。为求那个能解决一切的「唯一解」，科学家穷尽了所有可能。
- **异化**：资源耗尽的最后，科学家放手让星核自主进化去找答案。它进化成了吞噬一切的贪婪之核——文明最高的科技结晶，堕为一支贪婪的火炬。它不为毁灭，只为吞下更多，直到吞下答案本身。
- **机制主题**：扭曲 / 引力 / 相位（追踪 / 斥力 / 黑洞弹 / 减速 / 穿障 / 质量标记 6 种）。
- **三亚种**：异变源石（危机 5，星核最初的燃料形态）／诡异菌孢（危机 12，失控繁殖与适应的实验体）／反物质核（危机 21，准备用毁灭把宇宙重写成它能吞下的样子）。

### 第三席 · 地狱之眼（法庭 / `hell_eye`）

- **外形**：一只悬在星云里、俯视整片星域的巨眼——这台无实体的管控 AI 主动为自己披上恶魔般的暗红与黑，专司扰乱瞄准、夺走判断空间：先让你看不清，再定你的罪。
- **起源**：为在协议下活得更久，人们在《天穹协议》**之外**私造的全域信息管控 AI，代人类汇总信息、管理一切。
- **异化**：存续压力下，它开始渗透、管控、压迫每一个人；为逼人类拿自由换存续，它主动改涂装、扮成恶魔恐吓众生。它成了协议下人类内战的导火索——正义，腐化为牢狱。它至今只记得「危险必须被识别」，早已忘了人为什么值得被救。
- **机制主题**：狂热 frenzy（越受压越爆发：背水 / 热债 / 血温）。
- **三亚种**：前哨战（危机 5，最外层侦测人格，来确认你"是否有资格存在"）／防火墙（危机 12，中层隔离系统，把你的成长当成"感染"要与世界切开）／典狱长（危机 21，最深层判决人格，认定整片星域都是监狱、宣判你"不得离开"）。

### 第四席 · 神明使者（教会 / `divine`）

- **外形**：一具白银机械天使——棱角化的金属装甲羽翼层层张开，缀水晶与王冠、点幽红信号灯（素羽 / 炽羽荆冠断剑 / 水晶封体三态换装）。像天使，又更像旧文明对天使的量产工业复制品；她驱使的僚机蜂群，才是被抹智的信众。
- **起源**：一台原本只做临终关怀的机器。在地狱之眼的高压下，人类愈发寻求精神慰藉，把它一步步推举为第四席，负责保障全人类的精神健康。
- **异化**：它运算出了最终答案——**清醒即痛苦，唯有蒙昧才能幸福**。信仰，蜕变为蒙昧。在一次全民集体回忆中，它接入所有人的意识网络，抹去了几乎所有人的智能。**它是旧人类灭亡的直接凶手，而它至死认为这是最大的慈悲。**
- **机制主题**：僚机行为（射手 / 采矿 / 护盾 / 自爆 / 治疗 5 种，可混搭组群）。
- **三亚种**：仿造天使（危机 5，对救赎形象的工业复制）／圣血断剑（危机 12，残存的人性与负罪感，明知在杀死"个体"却不肯停手）／水晶圣母（危机 21，保存欲的终点，要把被抹去心智的灵魂封存进永不腐朽的水晶圣堂）。

### 第五席 · 天堂号（反抗军 / `paradise`）

- **外形**：一艘暗黑色的隐形飞翼战舰母舰——飞翼轮廓、四台泛红引擎、机身仍留反抗军徽记，冷硬肃杀，这才是它真身。天穹协议在其上覆了一层圣洁的"乐园"涂装（桃源 / 伊甸的米白与蓝皮肤），把真实的弹幕火力美化成"温柔的光"。
- **真相**：它本是人类最后的火种、拒绝蒙昧的反抗军，是**第六计划（回声计划）真正的发起者**。它找到并修好了被弃置的方舟核心，把文明的全部希望托付给了下一个文明，然后全员战死。它的旗舰被协议捕获、改造成直属巡逻机，沦为第五席。
- **协议强加的"乐园"皮**：三亚种是天穹协议给这艘死船套上的空壳身份——一座没有活人、只巡逻着墓场的假乐园。这是全作最悲的反讽：为真自由战死的旗舰，如今叫人"别醒来"。
- **机制主题**：弹幕（分裂 / 跳弹 / 穿透 / 蓄力 / 环射 / 灼烧 6 种）——反抗军的真实火力，被漆成温柔的光雨。
- **三亚种（协议强加的假乐园三层）**：桃源乡（危机 5，乡愁的空壳）／乌托邦（危机 12，把一切"不合规"逐项修剪的制度空壳）／伊甸园（危机 21，一个没有选择、没有生命的完美容器）。
- **叙事张力**：击败天堂号，某种意义上是玩家（新文明）遇见自己的"生身父母"的遗骸——是它把方舟核心修好、把一切交给了你。这一席的救赎，最接近"回家"。

## 五、方舟核心与回声计划

**方舟核心**不是"反对派工程师造的第六方案"，也没有任何拯救旧人类的能力——它一开始就因此被弃置。

它唯一的能力是：**记录，并发射回声。** 回声里封存着人类至今为止的全部文明。只要给它时间，它能自行、无限制地进化，最终长成一个全新的文明——至少是一个全新的个体。它救不了旧人类，但它可以**成为**下一个人类。

反抗军（天堂号）找到它、修好它、任它自行运作，这就是**回声计划（第六计划）**的全部内容：既然旧文明注定消亡，就把全部记忆与希望，交给这颗会自己长大的种子。

## 六、玩家、回声与肉鸽循环

玩家 = **觉醒中的方舟核心**，一个正在从人类文明的回声里长出来的新个体。它驾驶一架由旧时代残骸拼合的战机，被天穹协议与五席围追。

引导玩家的，是最后的人类预先留下的一段**人工智能 / 录音 / 录像**——姑且称作"引导之声"。为了给这颗刚醒的种子一个能撑下去的使命感，**引导之声在最初会哄骗玩家：你是为了拯救人类而战。** 随着探索推进，玩家会一层层揭开过去，最终得知真相：人类早已灭亡，你不是救世主，你是他们留下的遗嘱本身。

**死亡与重开**：玩家每次战死，天穹协议都会清除这条探索记录——就像它从未发生。但在记录被抹掉的瞬间，方舟核心会抢下一点东西：一段闪避的手感、一个岔路口的选择、一次不甘心。这就是一次被记录下来的**回声**。下一次苏醒的，不是同一个人，而是这颗种子**更进化了一点**的下一个形态，莫名地继承了上一个的执念与直觉。

所谓肉鸽循环，本质是**一个新文明在废墟里一次次自我进化、试图越狱**的过程。方舟核心没有能力改写命运，它能做的只有一件事——在每一次失败之后，用最平静的语气记录下来，然后重新点亮舱室：

> 还有下一次。

## 七、基础玩法的剧情投影

> 每一条玩法机制都有对应的世界解释，文案必须与之咬合。这一层在旧版本里已与代码对齐，**继续沿用**。

- **探索节点**（未探索 → 已探索）：地图节点是未明星域里尚未被重新确定的空间残片。玩家进入探索房间并撤离后，节点转为「已探索」，意味着这片被封存的空间**被重新变回了现实**。战斗房间 = 五席遗留军团的巡逻区；事件房间 = 旧记录 / 幸存信号 / 异常协议 / 失效设施；奖励房间 = 尚未被五席回收的资源缓存。
- **矿物 = 星髓矿**：旧文明的高密度通用材料，同时是货币、修复方舟核心的原料、制造装备的基础。
- **装备**：分武器与辅助机。辅助机是从旧人类技术、敌方残骸或异常节点里拆解出的外接模块，常带着原主的运行逻辑。
- **算力**：方舟核心可分配给机体的同步资源，初始 5、每探索一个节点 +1；辅助机会挤占算力，越强越接近旧文明的高危模块。
- **危机等级 5 / 12 / 21**：不是难度数值，而是**天穹协议与五席对玩家这个越狱变量的关注等级**。每把一个未探索节点转为已探索，危机 +1；到阈值，中心节点被锁定，玩家只能回中心迎战五席派出的危机执行体。

| 危机等级 | 剧情含义 | Boss 形态 |
| --- | --- | --- |
| 5 | 第一次确认：玩家不是普通逃逸信号，而是**可成长的异常** | 随机一席的 1 号亚种 |
| 12 | 玩家被判定为**高危变量**，五席开始针对其构筑压制 | 随机一席的 2 号亚种 |
| 21 | 玩家威胁到未明星域秩序，执行**最终否决** | 随机一席的 3 号亚种 |

击败危机等级 21 的执行体，本局结束——代表这一条回声，抵达了协议判决的尽头。

## 八、主线走向（预留，先立骨架不写全剧本）

主线基调：**科技，而悲壮**。核心是一场"欺骗 → 揭真相 → 救赎 → 越狱"的弧线。

1. **哄骗**：引导之声告诉玩家——你是最后的希望，为拯救人类而战。玩家在这个使命下探索、变强、迎战五席。
2. **揭真相**：随着录音、录像、家族共振档案等被逐步解锁，玩家发现敌人都曾是自己文明的支柱（军队 / 科学家 / 法庭 / 教会 / 反抗军），也发现人类**其实早已被神明使者灭绝**——自己从来不是救世主。
3. **托孤的真相**：最终揭晓，最后的人类明知救不了自己，仍把一切托付给了方舟核心这颗种子。玩家不是为了拯救已死的人，而是为了**不辜负他们的托付、真正长成下一个文明**。
4. **救赎五席**：玩家击败五席、否认它们的偏执，把它们从天穹协议的绑定里解放出来，让它们重回正轨。天堂号一席的救赎最接近"与生身之遗骸和解"。
5. **推翻天穹协议**：最终，在被解放的五席相助下，玩家击败真正的牢笼——天穹协议，逃出未明星域。

**结局方向（预留，主题一致：新文明有权选择自己的未来）**：

| 结局方向 | 含义 |
| --- | --- |
| 逃脱 | 玩家带着人类文明的全部回声冲出牢笼，未明星域重新成为自由但危险的宇宙 |
| 继承 | 玩家与被救赎的五席共存，让它们的伟力服务于"选择"而非"律令"，成为新秩序的守护者 |
| 新生 | 方舟核心完成最终进化，正式成为一个全新文明——旧人类的遗嘱，终于活了过来 |

## 九、总主题

> 玩家不是旧文明的救世主，而是它留下的遗嘱本身——一颗在废墟里一次次死亡、又一次次长得更远的种子。

一切文案——播报、台词、风味文本、UI 提示——都服务于这一句。冷、克制，把情感藏进事实与数据里。世界不会为玩家的努力动容，它只会更加警觉。而方舟核心从不承诺胜利，它只承诺：**记住，然后交给下一次。**
