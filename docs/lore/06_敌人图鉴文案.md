# 敌人图鉴文案（严肃向样例库）

> **定位**：`scripts/entities/designed_enemies/DesignedEnemyCatalog.gd`（25 个，每族 5：3 小怪 + 2 精英）里**已有** `mechanic` 战斗手感描述。本文件补充的是**图鉴/档案向的世界观 flavor**——不是打法说明，而是"这东西是什么、曾经是什么"。
> **若写回代码**，注意 `tools/designed_enemy_copy_quality_check.gd` 的约束。
> 每条：一句冷峻档案。它们都是五席遗留军团的碎片——**曾经也属于某个支撑过文明的机构**。
> 按新席序 1–5 排列；括注为美术色板与外形基调。

---

## 第一席 · 星间巨构（军队 · 钢灰 + 橙红 · 钢铁巨蟹的肢节）

| --- | --- |
| 巨构碎臂 | 「巨蟹折断的一只钳。它记得自己推平过多少城，却忘了当初为谁而行军。」 |
| 装甲盾蜂 | 「一整面会飞的封锁线，从巨蟹甲壳上剥落。战争时期造的，再没等到停战的指令。」 |
| 引力钩爪 | 「专门拖曳目标的巨蟹前爪。现在它分不清，你是挡路的障碍，还是待占的空间。」 |
| 巨构护卫（精英）| 「开拓兵团最后的编队。它护送的舰早已空无一人，它还在向前行军。」 |
| 核心吞噬者（精英）| 「以拆解其它机体为燃料的建造单元。让行军不停，就是它理解的延续文明。」 |

> 主题：幻影、扭曲瞄准、夺走视野与判断空间。它们不杀你，先让你看不清、先让你怕。

| --- | --- |
| 倒影眼虫 | 「隐入暗影，只留下偏移的伪影诱导判断。真正的突刺，往往来自视线边缘。」 |
| 盲点飞蛾 | 「专停在你注意不到的地方。审判从不在正面开始——它在你没看的那一侧。」 |
| 错位凝视者 | 「你以为它在那里，它其实在另一处。这台 AI 最擅长的，是让你先怀疑自己。」 |
| 颠倒司祭（精英）| 「把上和下、敌与我、罪与无辜统统调转。它守着旧文明用恐惧换来的秩序。」 |
| 视界偏转者（精英）| 「切开你和世界之间的视线。防火墙的本能：先隔离，再判断——如果还需要判断。」 |

> 主题：高速掠袭、闪现重定位、圣羽弹。像天使，又像天使的工业复制品。它们不想伤你，想抹去你。

| 折翼刺客 | 「一柄坏掉的圣物。它知道自己在抹去清醒，也知道那曾被叫做救赎——两者它都不肯放下。」 |
| 炽天追猎者（精英）| 「不知疲倦地追。它抹去过太多人的清醒，如今只剩下追上你、让你也安静这一件事。」 |

## 第五席 · 天堂号（反抗军 · 真身暗黑飞翼战舰，被协议漆成米白+蓝的"乐园"皮）

| 弧光散射机 | 「洒下一片柔光弹幕。协议要它温柔，可那本是掩护突围用的火。」 |
| 圣轨连射机 | 「按乐园的节拍连射。整齐得像一支安眠曲——间隙里，藏着当年的战斗节拍。」 |
| 天堂校准者（精英）| 「负责把不合规的现实修剪掉。你，就是它检出的第一处不合规——也是它半记得的、自己曾经的样子。」 |
