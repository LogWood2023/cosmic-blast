# 游戏内术语表与首见解释

本文件是玩家可见文案的术语来源；世界观细节仍以 `note/WORLDVIEW.md` 为准。

| 概念 | 游戏内固定写法 | 首次出现时的解释 |
| --- | --- | --- |
| 当前局内压力 | 危机关注度 | 完成节点会提高关注度；到达 5、12、21 时会出现首领并锁定普通航路。 |
| 出航前附加难度 | 出航难度 | 高阶危机的界面名称；每一等级都会累积一项额外规则。 |
| 装备容量 | 装配容量 | 决定本次航程还能安装多少装备；每件装备会占用一定容量。 |
| 货币 | 星髓矿 | 用于购买装备和刷新商品。 |
| 生命 | 机体结构／结构值 | 结构值归零即本次航程结束。 |
| 装备分类 | 武器／辅助装备 | 武器改变主火力；辅助装备提供附加能力或部署僚机。 |
| 同家族奖励 | 同家族加成 | 装配同一家族的辅助装备后获得额外效果。 |
| 商店偏向 | 商品偏好 | 刷新商品时，更容易出现指定家族的装备。 |
| 装备掉落概率 | 装备出现率 | 提高后，奖励与探索中更容易出现装备。 |
| 武器热量系统 | 武器过载 | 持续攻击会积累过载；充满后可进入强化状态。 |
| 首领 | 首领 | 天穹协议派出的执行体；“执行体”只在世界观氛围文本中使用。 |

## 文风规则

1. 机制句先说明效果、条件、持续时间与代价，再写氛围句。
2. 不用“纹章、同调、货单导向、装备检出、缓存校准、航路动能、重抽／重掷”等词代替玩法说明。
3. 世界观专名第一次出现必须可由同句、提示或档案条目理解；不得提前揭露新文明与人类结局。
