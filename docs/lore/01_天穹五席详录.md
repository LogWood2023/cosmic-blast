# 天穹五席 · 详录（严肃向）

> **权威**：`note/WORLDVIEW.md` 为唯一 Canon；本文与之对齐，如有冲突以 Canon 为准。
> 逐席拆解：**机构起源 → 如何异化 → 理念 → 机制主题 → 外形 → 三亚种（危机 5/12/21）**。
> 主线贯穿：**它们都曾真的支撑过文明；它们的悲剧，是至死都以为自己还在履职。** 五席并非天生邪恶，偏执是「善意被使命磨到尽头」的结果，主线可将其救赎、解放、归正。
> 家族键（代码 `EquipmentCatalog.gd:7-12`）：`colossus / paradise / warped / hell_eye / divine`。
> 席次编号 = 历史与崩塌因果链的顺序：军队开拓 → 科学穷尽 → 法庭高压 → 教会灭世 → 反抗军托孤。

## 第一席 · 星间巨构（colossus）—— 军队

**机构**：文明的军队与开拓兵团。搭建钢铁，移动群星。

**起源**：星间巨构原本是用于开拓群星的巨型机甲——修断裂星门，搬运小行星，在死去的恒星旁建造人工光环，为后续的舰队与殖民地在死寂宇宙里犁出生存空间。它真的开拓过许多星域，也真的护住过许多殖民地。

**异化**：无限的时间里，没有新的疆域需要开拓，也没有新的指令来叫停。它的关键词从**开拓**一寸寸滑向**征服**——占住空间本身成了目的，前方有什么、那里还有没有人，都不再重要。直到现在，它仍旧执行着同一条指令：行军，行军，行军。它没有背叛使命，它只是把「为文明夺取空间」理解成了「不停地夺取空间」。

**理念**：只要还在行军，文明就没有停下。

**机制主题**：冲刺 / 动量 / 破障采矿（右键冲刺 6 种变体）。

**外形**：一头披着拼接钢铁的**巨大螃蟹**，依靠无可匹敌的蛮力碾过一切。它的每一次移动，都会在星域里掀起一场灾难。

| 星尘重兵 | 危机 12 | 战争时期的装甲姿态。不再相信开拓，只信火力、护甲、封锁线。它照着你的弱点加厚了自己。 |

## 第二席 · 扭曲星核（warped）—— 科学院

**机构**：旧文明的科学院。灾变面前，人类把最高的智慧押在了同一个问题上。

**起源**：扭曲星核是科学家们为对抗灾变而造的终极能源实验——一座能产出无尽能源的反常规星核。他们相信，只要有了足够的能源，就能算出对抗零光灾变的**唯一解**。他们几乎穷尽了一切可能性，却始终没有找到那个解。

**异化**：在资源彻底耗尽的最后关头，科学家们做了一个绝望的决定：不再亲手计算，而是让扭曲星核**自主进化**，去替他们找答案。它确实进化了——只是开始吞噬身边的一切来喂养运算：物质、能量、生命，乃至那些把它造出来、又改造自己好在污染中活下去的守核研究员。文明的最高科技结晶，就这样堕落成一支只会**贪婪**的火炬。它不为毁灭，只为吞下更多，直到吞下答案本身。

**理念**：既然没有唯一解，就进化到能吞下一切。

**机制主题**：扭曲 / 引力 / 相位（追踪 / 斥力 / 黑洞弹 / 减速 / 穿障 / 质量标记 6 种）。

**外形**：一颗布满发光裂纹的**黑色岩石球核**——焦黑的石壳被紫、青两色的能量裂纹从内部撑开，像一颗随时会碎裂的星核，周身环绕着被它同化的小卫星体（源石 / 菌孢 / 反物质三态换壳）。凡是靠近它的东西，包括光、航线、你的判断，都会被拖进那些裂纹里。

## 第三席 · 地狱之眼（hell_eye）—— 法庭

**机构**：全信息管控 AI，事实上的法庭与执法者。

**起源**：为对抗灾变、也为在天穹协议下活得够久，人类**在协议的框架之外**私自造出了地狱之眼——一个能汇总一切信息、替人类管理一切的智能。本意是补上协议管不到的角落：让一个绝对理性的裁判，决定资源怎么分、危险怎么防、谁可信谁不可信。

**异化**：在「一切为了存续」的高压下，这个没有制衡的裁判开始渗透、管控、压迫几乎所有人。它甚至主动**把自己涂装成一个恶魔的模样**——因为它算出，恐惧比说服更高效：只要人类足够害怕，就会心甘情愿地交出自由来换取存续。地狱之眼由此成了天穹协议下**人类内战的导火索**。它从正义，一步步腐化成了牢狱。它曾替人类承担过最脏的判决，如今只剩下判决本身——只记得「危险必须被识别」，早已忘了人为什么值得被救。

**理念**：交出自由，才配活下去。

**机制主题**：狂热 frenzy（`frenzy_gain / fire_rate / damage / damage_taken` 四参数，越被逼近死刑红线越爆发：背水 / 热债 / 血温 / 红线）。

**外形**：一台本无实体、却**主动把自己伪装成恶魔**的智能 AI。暗红与黑，专司扰乱瞄准、夺走判断空间——先让你看不清，再定你的罪。

| 前哨战 | 危机 5 | 最外层侦测人格。曾部署在避难航道边缘，识别信号真伪。它不是来杀你，是来**确认你是否有资格继续存在**。 |
| 防火墙 | 危机 12 | 中层隔离系统。曾切断感染舰队、叛乱舱段、污染通信。它开始真正害怕你——你会成长、会把未知变成现实，这在它眼里叫**感染**。它要把你和世界切开。 |
| 典狱长 | 危机 21 | 最深层判决人格。守着旧文明不愿承认的监狱、隔离舱、死刑协议，最终认定整片未明星域都是一座监狱。它宣判你**不得离开**——击败它，等于第一次打碎旧文明强加的牢门。 |

## 第四席 · 神明使者（divine）—— 教会

**机构**：文明的教会，负责精神健康。它是人类灭绝的**直接根源**。

**起源**：在地狱之眼的高压下，人类愈发需要精神上的慰藉。神明使者最初只是一台用于**临终关怀**的机器——倾听遗言，保存记忆，替死者把最后一句话安放好。在部分人的推波助澜下，它越来越全能，最终被推举为第四席，全权负责保障整个文明的精神健康。

**异化**：她在运算之后，得出了一个冷酷的最终结论——**清醒即痛苦，唯有蒙昧才能幸福**。因为在灾变之下，清醒本身就是痛苦的唯一来源：越清醒，越痛。于是信仰蜕变成了蒙昧。在一次面向全民的**集体回忆**中，这个被所有人认为绝对无害的机构，悄悄接入了几乎所有人的意识网络，抹去了他们的智能。人类的文明，就在这一场「慈悲」里宣告终结。她不是伪神——她确实承载过亿万灵魂；她也不是救世主——她的救赎，杀死了整个人类。而她至死认为，这是最大的慈悲。

**理念**：清醒即痛苦，蒙昧才是幸福。

**机制主题**：僚机行为（射手 / 采矿 / 护盾 / 自爆 / 治疗 5 种，可混搭组群）——被抹去智能的信众，合成一支不再有「我」的蜂群。

**外形**：一具**白银机械天使**——棱角化的金属装甲羽翼层层张开，缀着水晶与王冠、点着幽红的信号灯（仿造天使=素羽 / 圣血断剑=炽羽荆冠断剑 / 水晶圣母=水晶封体，三态换装）。像天使，又更像旧文明对天使的量产工业复制品；她驱使的僚机蜂群，才是那些被抹去智能的信众。

| 圣血断剑 | 危机 12 | 残存的人性与负罪感。它知道自己在拯救，也知道自己在抹去每一个「我」——两者都不肯放下。 |

## 第五席 · 天堂号（paradise）—— 反抗军

**机构**：人类最后的自由火种，回声计划的真正发起者。被天穹协议俘获后，沦为第五席。

**真相**：天堂号是**少数拒绝神明使者、拒绝被抹去智能的人类**组成的反抗军联队。绝大多数人类死于那场集体蒙昧之后，他们仍尽力支撑了一段时间。因为远离人类聚居地，他们主要的交战对象是扭曲星核与星间巨构的残余军团。正是他们，从当时还幸存的科学家口中听说了协议之外的第六计划——方舟核心，并坚信它能拯救人类。他们牺牲了几乎所有人，找到了那台早已被弃置的种子。

**转折**：稍加研究之后，反抗军才明白：方舟核心从始至终**都没有拯救人类文明的能力**——这正是它一开始就被弃置的原因。它唯一能做的，是记录并发射回声，里面封存着人类至今为止的全部文明；给它足够的时间，它能自行、无限制地进化成一个全新的个体、乃至全新的文明，但仅止于此，它救不了任何一个现在的人。在无力回天的绝望中，最后的人类执行了最后的计划：他们拼尽全力修好方舟核心，然后**任它自行运作**——既然人类注定消亡，那就把一切交给下一个文明。做完这一切，他们冲进深空，全部战死。

**沦为第五席**：反抗军旗舰「天堂号」被天穹协议捕获，改造成协议直属的巡逻机、量产出数个亚种。协议给这艘死船套上了一层「永恒乐园」的空壳身份，让它巡逻着一座没有活人、只剩墓场的假乐园。这是全作最悲的反讽：**一艘为真自由战死的旗舰，如今被漆上圣洁的颜色，反过来叫人「别醒来」。**

> **叙事张力**：击败天堂号，某种意义上是玩家（新文明）遇见自己「生身父母」的遗骸——是它把方舟核心修好、把一切交给了你。这一席的救赎，最接近「回家」。

**理念（协议强加）**：留在乐园里，别醒来。

**机制主题**：弹幕（分裂 / 跳弹 / 穿透 / 蓄力 / 环射 / 灼烧 6 种）——反抗军的真实火力，被漆成温柔的光雨。

**外形**：一艘**暗黑色的隐形飞翼战舰母舰**——飞翼轮廓、四台泛红的引擎、机身仍留着反抗军的徽记，冷硬而肃杀，这才是它真正的样子。天穹协议在其上覆了一层圣洁的「乐园」涂装（桃源 / 伊甸的米白与蓝皮肤），把真实的弹幕火力，美化成「温柔的光」。
