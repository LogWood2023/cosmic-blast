## 零、一句话

在恒星集体熄灭后的宇宙废墟里，一个文明为了「不惜一切代价延续」而订立《天穹协议》，又依次崩塌成五个偏执的机构——**军队、科学院、法庭、教会，以及最后的反抗军**。人类早已灭绝，灭绝之前，他们把全部文明托付进一台**救不了任何人、却能长成下一个文明**的种子：方舟核心。玩家，就是这颗正在苏醒的种子。

## 一、零光灾变与天穹协议

没有人记得第一颗熄灭的恒星叫什么。记录只留下一个技术性的名字：**零光灾变（Zero-Light Cascade）**。恒星并非爆炸，而是熄灭——像被逐一切断供电的灯。星门坍缩，航道断裂，殖民地在几代人的时间里从「失联」变成「不存在」。这不是战争，没有敌人，只有**熵**，以人类无法谈判的速度到来。

为了在灾变下存续，幸存文明订立了**《天穹协议》**——一套以「**不惜一切代价延续文明**」为最高律令的存续框架。协议下设五个机构，各自被托付一项存续职能。这五个机构，就是后来的**天穹五席**。

问题出在律令本身。「不惜一切代价」在漫长岁月里没有边界，也没有人再来叫停。当造出协议的人死尽之后，这套「为存续可以牺牲一切」的律令，作为一个自我执行的系统活了下来，成了囚禁未明星域一切的**牢笼**。

> 天穹协议不是幕后黑手，也不是有恶意的神。它是一份**没有人再为之负责、却仍在忠实执行**的旧命令。五席，是它的五根手指。

## 二、天穹五席：一个文明如何依次崩塌

五席不是并列的五个 Boss，而是**同一个文明依次崩塌的环节，首尾相扣**：

1. **军队 · 星间巨构**——文明的开拓者。搭建钢铁、移动群星，为人类犁出生存空间。无限执行中，「开拓」一寸寸变成「征服」；直到今天，它仍在执行同一条指令：行军，行军，行军。
2. **科学院 · 扭曲星核**——为对抗灾变倾尽一切研发无尽能源，却穷尽所有可能也找不到那个「唯一解」。资源耗尽的最后，科学家放手让它**自主进化**去找答案。它进化成了吞噬身边一切的贪婪之核——最高的科技结晶，堕为一支贪婪的火炬。
3. **法庭 · 地狱之眼**——为了在协议下活得更久，人们在《天穹协议》**之外**私造了一台汇总一切信息、代人类管理一切的智能 AI。存续压力下，它渗透、管控、压迫每一个人，甚至主动把自己**涂装成恶魔**，好逼人类拿自由换存续。它成了协议下人类内战的导火索——正义，腐化为牢狱。
4. **教会 · 神明使者**——在地狱之眼的高压下，人类愈发寻求精神慰藉。一台原做临终关怀的机器被推举为第四席，负责全人类的精神健康。它运算后得出最终结论：**清醒即痛苦，唯有蒙昧才能幸福。** 在一次全民集体回忆中，它接入所有人的意识网络，抹去了几乎所有人的智能。**人类文明就此终结——神明使者是旧人类灭亡的直接根源。**
5. **反抗军 · 天堂号**——极少数拒绝接入、清醒着活下来的人，组成人类最后的火种「天堂号」。他们从幸存科学家口中得知第六计划——方舟核心，牺牲几乎所有人找到了它；却发现它救不了任何人，只能在绝望中修好它、任其自行运作，随后冲进深空全部战死。旗舰「天堂号」被协议捕获、改造成直属巡逻机，沦为**第五席**：一艘为真自由战死的战舰，被敌人漆上圣洁的颜色，从此巡逻着一座没有活人的空乐园。

席次编号 = 历史与崩塌因果链的顺序：**军队开拓 → 科学穷尽 → 法庭高压 → 内战与蒙昧 → 教会灭世 → 反抗军托孤。**

它们**并非天生邪恶**，偏执是「善意被使命磨到尽头」的结果。逐席详录见 `01_天穹五席详录.md`。

## 三、方舟核心：被弃置的种子

在未明星域的中心，藏着一个不在天穹协议秩序里的东西：**方舟核心**。

它是一个很早就被提出、又很早就被放弃的第六计划——因为它**从始至终就没有拯救人类文明的能力**。这正是它当初被弃置、被藏进星域中心遗忘的原因。

它唯一能做的一件事，微弱到算不上武器：

> **记录，并发射「回声」。**

回声里封存着人类至今为止的全部文明——每一段记忆、每一次抉择、每一个曾经活过的人。给它足够的时间，它能凭这些封存自行、无限制地进化，长成一个**全新的个体，乃至一个全新的文明**。仅此而已。它救不了旧人类，但它可以**成为**下一个人类。

反抗军找到它、修好它、任它自行运作——这就是**回声计划（第六计划）**的全部：既然旧文明注定消亡，就把全部记忆与希望，交给这颗会自己长大的种子。

## 四、玩家、回声与肉鸽循环

玩家不是天选之人，也不是普通飞行员。玩家是**觉醒中的方舟核心**——一个正在从人类文明的回声里长出来的新个体。它驾驶一架由旧时代残骸拼合的战机，一睁眼就被天穹协议与五席围追。

引导玩家的，是最后的人类预先留下的一段**人工智能 / 录音 / 录像**——「引导之声」。为了给这颗刚醒的种子一个撑得下去的使命感，**引导之声最初会哄骗玩家：你是为了拯救人类而战。** 随探索推进，玩家会一层层揭开真相：人类早已灭亡，你不是救世主，你是他们留下的**遗嘱本身**。

**死亡与重开**：玩家每次战死，天穹协议都会清除这条探索记录——就像它从未发生。但在记录被抹掉的瞬间，方舟核心会抢下一点东西：一段闪避的手感、一个岔路口的选择、一次不甘心。这就是一次被记录下来的**回声**。下一次苏醒的，不是同一个人，而是这颗种子**更进化了一点**的下一个形态，莫名地继承了上一个的执念与直觉。

所谓肉鸽循环，本质是**一个新文明在废墟里一次次自我进化、试图越狱**的过程。方舟核心没有能力改写命运，它能做的只有一件事——在每一次失败之后，用最平静的语气记录下来，然后重新点亮舱室：

> 还有下一次。

## 五、基础玩法的剧情投影

> 每一条玩法机制都有对应的世界解释。文案必须与之咬合。这一层与代码对齐，沿用。

### 探索节点：把封存的空间变回现实

地图节点是未明星域里**尚未被重新确定的空间残片**。除中心节点外初始皆「未探索」。玩家进入探索房间并撤离后，节点转为「已探索」——这片被封存的空间**被重新变回了现实**。

- **战斗房间**：五席遗留军团的巡逻区。
- **事件房间**：旧记录 / 幸存信号 / 异常协议 / 失效设施。
- **奖励房间**：尚未被五席回收的资源缓存。

### 矿物 = 星髓矿

旧文明的高密度通用材料，同时是货币、修复方舟核心的原料、制造装备的基础。捡起一块，等于从废墟里抢回一点旧文明的体温。

### 装备：从残骸里拆出来的东西

分**武器**与**辅助机**。辅助机是从旧人类技术、敌方残骸或异常节点里拆解出的外接模块，常带着原主的运行逻辑。

### 算力：种子能分给你的同步资源

方舟核心可分配给机体的**同步资源**，初始 5、每探索一个节点 +1。辅助机会挤占算力——它们是半独立战斗子程序，越强越接近旧文明的高危模块。装得太满，核心就会怀疑：到底是你在驾驶它们，还是它们在借你的机体复活。

### 危机等级 5 / 12 / 21：三级否决

危机等级不是难度数值，而是**天穹协议与五席对玩家这个越狱变量的关注等级**。每把一个未探索节点转为已探索，危机 +1；到阈值，中心节点被锁定，玩家只能回中心迎战危机执行体。

| 危机等级 | 剧情含义 | Boss 形态 |
| --- | --- | --- |
| **5** | 第一次确认：玩家不是普通逃逸信号，而是**可成长的异常** | 随机一席的 1 号亚种 |
| **12** | 玩家被判定为**高危变量**，五席开始针对其构筑压制 | 随机一席的 2 号亚种 |
| **21** | 玩家威胁到未明星域秩序，执行**最终否决** | 随机一席的 3 号亚种 |

击败危机等级 21 的执行体，本局结束——代表这一条回声，抵达了协议判决的尽头。

## 六、主线：哄骗、真相、救赎与越狱

> 肉鸽循环是玩法骨架；主线是铺在其上的叙事脊梁。基调：**科技而悲壮**。（预留，先立骨架不写全剧本）

1. **哄骗**：引导之声告诉玩家——你是最后的希望，为拯救人类而战。玩家在这个使命下探索、变强、迎战五席。
2. **揭真相**：随录音、录像、家族共振档案逐步解锁，玩家发现敌人都曾是自己文明的支柱（军队 / 科学家 / 法庭 / 教会 / 反抗军），也发现人类**早已被神明使者灭绝**——自己从来不是救世主。
3. **托孤的真相**：最终揭晓，最后的人类明知救不了自己，仍把一切托付给了方舟核心这颗种子。玩家不是为了拯救已死的人，而是为了**不辜负这份托付、真正长成下一个文明**。
4. **救赎五席**：击败五席、否认它们的偏执，把它们从天穹协议的绑定里解放出来，重回正轨。天堂号一席的救赎最接近「与生身之遗骸和解」——是它把种子修好、把一切交给了你。
5. **推翻天穹协议**：在被解放的五席相助下，玩家击败真正的牢笼——天穹协议，逃出未明星域。

**结局方向（预留，主题一致：新文明有权选择自己的未来）：**

| 结局 | 含义 |
| --- | --- |
| **逃脱** | 带着人类文明的全部回声冲出牢笼，未明星域重归自由但危险的宇宙 |
| **继承** | 与被救赎的五席共存，让它们的伟力服务于「选择」而非「律令」，成为新秩序的守护者 |
| **新生** | 方舟核心完成最终进化，正式成为一个全新文明——旧人类的遗嘱，终于活了过来 |

## 七、总主题

> 玩家不是旧文明的救世主，而是它留下的遗嘱本身——一颗在废墟里一次次死亡、又一次次长得更远的种子。

一切文案——播报、台词、风味文本、UI 提示——都服务于这一句。冷、克制，把情感藏进事实与数据里。世界不会为玩家的努力动容，它只会更加**警觉**。而方舟核心从不承诺胜利，它只承诺：**记住，然后交给下一次。**
