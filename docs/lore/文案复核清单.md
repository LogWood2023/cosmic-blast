# 文案复核清单

## 已落地

- 事件选项显示代价、结果与风险。
- 主菜单档案、敌人档案、术语解释、首领阶段提示、战败回声说明已接入。
- 危机关注度、出航难度、装配容量、装备出现率、商品偏好、同家族加成、武器过载为当前规则层正式名称。

## 每次新增内容必须复核

1. 装备风味句不得宣称属性表中不存在的数值或行为；效果行必须来自实际属性。
2. 新事件必须展示成本、持续节点和结果，不能只展示氛围文本。
3. 新信标必须提供中文标题、效果说明与风险说明，禁止显示 `rule_key`。
4. 新首领或敌人必须提供档案条目，并在首次遭遇后解锁。
5. 玩家可见文本不得包含测试字样、内部 ID、英文状态串或未经解释的机制缩写。
