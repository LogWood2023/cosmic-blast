# 装备风味文案（严肃向样例库）

> **定位**：`scripts/core/EquipmentCatalog.gd`（约 142 件）里**已有** flavor 文本。本文件不冒充权威覆盖，而是提供**严肃向的补充/可替换样例**，供挑选或统一基调时参考。
> **若要写回代码文案表**，需先过 `tools/equipment_copy_quality_check.gd` 的长度/禁词/风格约束。
> **语气模板**：机制现象化 + 星域名词 + 2–3 句短句，动词密集，不喊口号。稀有度越高越冷、越带灾厄感。
> **家族基调**（对齐新设定）：巨构=军队/征服；星核=科学院/吞噬；地狱之眼=法庭/交自由；神使=教会/蒙昧；天堂号=反抗军真枪，被协议漆成假乐园的光。

## 武器（主炮）· 严肃向一句样例

> 武器多为通用/星象命名，基调偏冷硬。

- **脉冲机炮**：「最朴素的一门炮。回声的第一课：先活下来，再谈别的。」
- **星轨钉刺炮**：「沿旧航道钉出一串火。这些航道，曾通往还亮着的星。」
- **彗尾撕裂炮**：「拖着一条燃烧的尾。像一颗不肯熄灭的、迟到了几千年的彗星。」
- **虚空锯链**：「近距离的绝望武器。当星髓和体面都用光时，还剩它。」
- **陨锤炮**：「把一小块死星砸出去。宇宙杀死人类的方式，现在归你借用。」
- **日冕绽放**：「一次性的假黎明。照亮战场，也照亮你不愿看清的东西。」
- **神谕束流**：「一道会自己寻的光。它温柔地找到目标——温柔得让人不安。」
- **霜线轨炮**：「沿着零度的线开火。恒星熄灭后，整片星域都是这个温度。」
