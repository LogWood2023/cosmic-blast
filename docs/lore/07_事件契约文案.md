# 事件 · 契约 · 矿源 · 星域异象文案（严肃向样例库）

> **定位**：这些系统在 `RunManager.gd` 里**已有** `description` / `flavor` / `room_effect_text` / `effects_text`。本文件提供**严肃向补充样例**。写回代码前留意对应 `tools/*_check.gd`（`event_contract_*`、`ore_source_*`、`run_condition_variety_check.gd`、`reward_cache_*`、`route_directive_*`）。
> 抓手：事件房间 = 旧记录 / 幸存信号 / 异常协议 / 失效设施。契约多有代价——**在末世里,没有免费的补给**。
