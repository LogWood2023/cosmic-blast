# 未明星域 · 世界观与文案集（严肃向）

> 本目录是《Cosmic Blast》的世界观圣经与游戏内文案库，基调：**硬科幻、末世、严肃、宿命**。
> 它在 `note/WORLDVIEW.md` 既有设定骨架之上做**严肃化重写与扩写**，不推翻任何已与代码对齐的核心设定。

## 与既有设定的关系

- **不改动** `note/WORLDVIEW.md`。该文件是设定的原始骨架（五席、方舟核心、回声、危机等级 5/12/21、矿物/算力），全部沿用。
- 本目录负责两件事：
  1. 把基调从「二次元科幻悲壮」收敛为「冷峻、克制、严肃的末世硬科幻」；
  2. 把设定落成**可直接进游戏的文案**（播报、台词、风味文本、UI 提示）。

## 风格基准（写任何新文案都遵守）

| 维度 | 要求 | 反例（避免） |
| --- | --- | --- |
| 语气 | 冷、重、克制，信息密度高，少形容词 | 热血、卖萌、抒情堆砌 |
| 视角 | 系统日志 / 战术播报 / 档案残片 / 敌方独白 | 旁白直接煽情 |
| 情感 | 藏在事实与数据里，不喊出来 | "多么悲壮啊" |
| 神性/温柔 | 呈现为**冷酷的逻辑结果**，不软化 | 少女、樱花、治愈 |
| 专有名词 | 与代码/既有设定完全一致 | 自造与机制冲突的新名词 |
