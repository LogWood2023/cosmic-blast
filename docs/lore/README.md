# 未明星域 · 世界观与文案集（严肃向）

> 本目录是《Cosmic Blast》的世界观圣经与游戏内文案库，基调：**硬科幻、末世、科技而悲壮、宿命循环**。
> **单一剑权**：`note/WORLDVIEW.md` 是世界观的唯一权威正典；本目录 `00`/`01` 是与之对齐的严肃化正文与逐席详录，`02`~`07` 是落成文案。三者如有冲突，以 `WORLDVIEW.md` 为准。

## 设定重构说明（相对最初版本）

最初的文案是"看名字直接写的设计"，与后续敲定的设定已不符。当前正典做了四处结构性重构：

1. **五席 = 五个机构**，而非"最后会议同时封存的五种方案"——军队 / 科学院 / 法庭 / 教会 / 反抗军，序号即成立/被收编的先后，也是一条文明依次崩塌的因果链。
2. **天穹协议 = 牢笼**：由"与五席平级的中立仲裁核心"改为"最初中立、后在无人监督中僵化，役使并收编五席、覆盖整片星域的牢笼系统"，是主线终局要击破、逃离的对象。
3. **方舟核心 = 被弃遗物**：由"工程师私造的第六方案"改为"没有护文明之力、当初即被抛弃、唯一能力是记录并发射回声、终将孕育出下一个文明的遗物"。反抗军（天堂号）才是"第六计划/回声计划"真正的发起者。
4. **玩家 = 人类的遗产，而非救主**：旧人类已被教会（神明使者）灭绝；玩家是方舟核心发射的回声，受一段亡者留下的引导 AI 指引——引导 AI 起初哄骗玩家"为拯救人类而战"，主线中逐层揭开真相。

## 风格基准（写任何新文案都遵守）

| 维度 | 要求 | 反例（避免） |
| --- | --- | --- |
| 语气 | 冷、重、克制，信息密度高，少形容词 | 热血、卖萌、抒情堆砌 |
| 视角 | 系统日志 / 战术播报 / 档案残片 / 敌方独白 | 旁白直接煽情 |
| 情感 | 藏在事实与数据里，不喊出来 | "多么悲壮啊" |
| 神性/温柔 | 呈现为**冷酷的逻辑结果**，不软化 | 少女、樱花、治愈 |
| 专有名词 | 与代码/正典完全一致 | 自造与机制冲突的新名词 |
