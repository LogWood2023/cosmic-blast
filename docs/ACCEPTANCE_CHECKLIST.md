## 一、阶段2 战斗画面 / Game Feel

### - [ ] 1. 战斗背景星空
- **怎么验**：进任意普通战斗（主菜单→开始）与任意 Boss 战。
- **看什么**：不再是纯黑，是深空星云 + 漂移星点背景；弹幕仍清晰可读（背景压暗）。
- **覆盖**：普通战斗 `main.tscn` + 全部 20 个 `BossBattle_*.tscn`。
- **提交**：`5ba8855`

### - [ ] 2. 受击闪白
- **怎么验**：打普通敌机、设计敌（25 种）、Boss 部件；被敌人打到看玩家机。
- **看什么**：命中瞬间目标精灵闪一下白（约 0.09s）。
- **覆盖**：所有敌人（含 DesignedEnemy 经继承）、Boss 部件受击、玩家 3 个受击入口。
- **提交**：`5ba8855`（`scripts/fx/HitFlashFx.gd`）
- **可调**：闪白时长（`HitFlashFx.DURATION`）。

### - [ ] 3. 镜头震动（+ hitstop 已移除）
- **怎么验**：受伤（中震）、击杀敌人（轻震）。
- **看什么**：镜头轻微抖动衰减；**受伤后不再卡顿/慢放**（你之前反馈的卡顿源 hitstop 已删）。
- **提交**：`5ba8855` + `9cfbf23`（移除 hitstop）
- **可调**：`CameraFeedback.gd` 顶部 `MAX_OFFSET`、受伤/击杀 trauma 值（0.35 / 0.12）。

### - [ ] 4. 低血暗角
- **怎么验**：把玩家血量打到 40% 以下。
- **看什么**：屏幕边缘泛起脉动红色暗角、越低越强；中心透明不挡视野与中央 HUD。
- **覆盖**：`main.tscn` + 全部 20 Boss 战。
- **提交**：`5caec6e`
- **可调**：`LowHpVignette.gd` 的 `APPEAR_BELOW`(0.4 出现阈值)、`MAX_INTENSITY`(0.85)。

### - [ ] 5. 爆炸特效增强
- **怎么验**：击杀任意敌人 / Boss；放炸弹；探索炮台爆炸。
- **看什么**：爆炸有 ① 缩放过冲 punch ② 加色扩张冲击环 ③ 初始亮闪核心 ④ 全向迸射火花。
- **覆盖**：中心化增强 `Explosion.gd`，惠及所有爆炸调用点（敌人/自爆/炸弹/炮台/全部 Boss）。
- **提交**：`558b8cb`（过冲+环+亮闪）+ `cae9cce`（火花）
- **可调**：`ExplosionFlash.gd`（环/核心颜色、LIFE）、`ExplosionSparks.gd`（数量/速度/颜色）。

### - [ ] 6. 玩家推进器尾焰
- **怎么验**：进战斗看玩家机；WASD 移动看尾焰随朝向摆动。
- **看什么**：机尾喷出青白色加色火焰（**你已确认朝向正确**）。
- **提交**：`81293f8`（`scripts/fx/Thruster.gd`）
- **可调**：`Thruster.gd` 的 AMOUNT/LIFETIME、速度、颜色渐变；挂点 `player.tscn` 的 `Thruster` 位置 (0,20)。

### - [ ] 7. 狂热光环
- **怎么验**：触发狂热（frenzy）状态。
- **看什么**：玩家周身泛起琥珀→红的旋转能量涡旋；狂热结束即熄。
- **提交**：`cd1d83b`（`scripts/fx/FrenzyAura.gd`）
- **可调**：`FrenzyAura.gd` 的 AMOUNT/轨道速度/环半径/颜色。

### - [ ] 8. 矿石回收粒子流光
- **怎么验**：探索中采集星髓矿（普通/富矿）。
- **看什么**：回收光点飞向玩家时留下火花尾迹（叠在原有 Line2D 流光上），颜色随矿石类型（普通青、富矿琥珀）。
- **提交**：`c01279b`（`scripts/fx/MineralTrail.gd`）
- **可调**：`MineralTrail.gd` 的 AMOUNT/速度/尺寸。

## 二、阶段1 UI

### - [ ] 9. 全局中文字体（发布风险修复）
- **怎么验**：看任意界面的中文文字。
- **看什么**：中文统一用**思源黑体**（内嵌，不再依赖系统 fallback 字体）。这是发布安全项。
- **覆盖**：全局 Theme `assets/theme/main_theme.tres`，所有 UI 文字。
- **提交**：`b234213`

### - [ ] 10. 标题字体
- **怎么验**：主菜单、GameOver、BossSelect、WorldMap、Boss 战 HUD。
- **看什么**：
  - 主菜单大标题「星际战机」加粗（DisplayTitle）；
  - 主菜单 5 个序号 `01`–`05` 用 Orbitron 科技感数字（HudReadout）；
  - GameOver「游戏结束」、BossSelect「执行体挑战」、WorldMap「方舟核心航图」、BossHUD Boss 名 → 加粗。
- **提交**：`1d55a98` + `a432c7c`
- **备注**：混排中文+数字的读数（分数等）保持思源黑体，未套 Orbitron（无中文字形会 fallback）。

### - [ ] 11. Theme 默认 StyleBox（地基，几乎无可见变化）
- **怎么验**：一般无需专门验——现有界面控件几乎都自带 override，外观不变。
- **看什么**：无明显变化即为正常（这是给未来/未 override 控件的兜底与设计单一真源）。
- **提交**：`15f63fa`
- **备注**：**未做**全项目 override 清除（很多 override 是有意的语义化配色，如 GameOver 红色终局边框，不宜无脑清）。若想真正统一某界面，需逐屏审美拍板、选择性做。

## 三、性能（已验，无需动作）

### - [ ] 12. 对象池 —— 实测确认不需要
- **结论**：MCP 压测（每秒 ≈48 爆炸[含冲击环/火花]+ 数百碎片，远超实战）下**稳态 59–60 FPS**、节点 500–800 波动无卡顿（GTX 1650）。子弹 `_process` 的 homing/重力扫描本就有早退守卫+限流。故对象池是过早优化，**未做**、无改动。
- **验收**：无需操作，知悉即可。
